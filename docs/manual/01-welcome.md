# Welcome to Toren Linux

Toren Linux is Void Linux with the Hyprland compositor and a custom Quickshell desktop, set
up for you and kept up to date by Toren's own tools. Windows tile next to each
other instead of overlapping, and almost everything has a keyboard shortcut.

## Your first five minutes

1. Press **Super + K** to see every shortcut. (Super is the Windows key.)
2. Press **Super + Space** and type the name of an app to open it.
3. Press **Super + Enter** for a terminal.
4. Run `toren theme set` to pick a look, and `toren bundle` for ready-made app sets.
5. Run `toren doctor` once: it checks the whole machine and tells you if
   anything is wrong.
