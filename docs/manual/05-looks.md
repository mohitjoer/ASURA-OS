# Looks: themes and wallpapers

```sh
toren theme set           # the looks
toren theme set sakura    # switch
```

A look sets the wallpaper, light or dark, and the colours, and the bar,
terminal, system monitor and GTK apps all follow. Looks: berserk, unit-01,
ink, paper, sakura, garden, forest, cherry, kaiju, rain, samurai, kurzgesagt.

Your own wallpaper: **Super + W** picks one (colours follow it), **Super +
Shift + W** picks one at random. Put your pictures in `~/Pictures/Wallpapers`.
