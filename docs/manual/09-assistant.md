# The AI assistant

Toren installs **OpenCode**, a coding and system assistant that runs in the
terminal, and gives it Toren's own knowledge: how this desktop works, how to
update, install, theme and fix it. Run `opencode` in a terminal and ask, for
example, "make the dock always visible" or "why is my Wi-Fi slow".

It needs an AI provider account (OpenCode asks on first start). It asks before
it runs commands; read them before you agree, especially anything with sudo.

`toren-agent status` shows which assistants on this machine have Toren's
knowledge; they are set up at every login.
