# Toren Linux 0.1.0-beta.1

Toren Linux is a Linux distribution built on Void Linux x86_64 (glibc, runit,
XBPS) with the Hyprland compositor and a Quickshell desktop. It is set up and
kept up to date by its own `asura` tools. This is the first beta: install it on
a machine you can afford to wipe.

## Get it

1. Download `asura-os-0.1.0-beta.1-x86_64.iso` and `SHA256SUMS` from the
   release page below.
2. Verify it: `sha256sum -c SHA256SUMS` must print `OK` for the ISO.
3. Write it to a USB stick and boot it with **Secure Boot turned off**.
4. Open **Install Toren Linux** on the desktop and follow the installer.

## What is in this beta

- **Desktop:** Quickshell desktop with a top bar, hiding dock, control centre,
  overview and launcher, and colours derived from the wallpaper. Hyprland
  **0.57.2** comes from Toren's signed package repository (the ISO retains the
  older 0.49 stack as a fallback if the repository cannot be reached).
- **Updates:** `asura update` installs the newest build whose CI passed, takes
  a Btrfs snapshot before system changes, and refreshes the running desktop
  without a logout. `asura rollback` goes back.
- **Migrations:** `asura migrate` applies one-time fixes to installed machines,
  including trusting the repository signing key and enabling new services.
- **System services:** socklog system logging, weekly fstrim / monthly btrfs
  scrub via a runit maintenance service, earlyoom OOM protection, and thermald
  on Intel machines. See `docs/system-services.md`.
- **Diagnostics:** `asura doctor` and `asura doctor --json` check the machine;
  `journalctl` reads the socklog logs; `asura hardware report` produces a
  redacted hardware profile.
- **Optional services:** `asura enable docker` (also bluetooth, printing, ssh,
  libvirt, tailscale) installs, starts and configures a service in one command.
- **Firewall:** incoming connections are blocked by default.

## Known issues

- **Secure Boot is not supported.** Turn it off in firmware to boot the ISO and
  the installed system.
- The final list of hardware-specific issues will be recorded here after the
  real-hardware test (boot, desktop, Wi-Fi, audio, brightness, suspend/resume,
  installer and `asura update`). Until that test is complete this beta is not
  recommended for daily use.
- Installs through the Store do not take a snapshot yet; installs through
  Toren's own tools do.
- Checksums are signed only when the release key is configured; otherwise the
  release ships `SHA256SUMS` alone.

## How to update an installed system

```sh
asura update
```

`asura update` pulls the newest build whose CI passed, installs it from the
signed repository, and reloads the desktop. To inspect or undo a system change:

```sh
asura snapshot
sudo asura rollback --system NAME
```

## Report a problem

Open an issue at <https://github.com/mohitjoer/ASURA-OS/issues> with:

- `asura version -v`
- `asura doctor --json`
- `~/.local/state/asura/quickshell.log` for desktop problems
- a redacted `asura hardware report --profile` when the problem is hardware
  specific
