# The Quickshell Desktop

`shell-desktop/` is Toren's primary Quickshell desktop:
the complete Quickshell config (bar, vertical bar, dock, left and right sidebars, overview
and search, notifications, OSD, media controls, cheatsheet, lock screen, session menu, region
selector, screen corners, overlay widgets, wallpaper selector, settings), at the commit pinned in
`vendor.sh`. It is the default desktop shell: `org.toren.shell desktop-shell` is `desktop`.

## Switching

```bash
gsettings set org.toren.shell desktop-shell toren     # ASURA's minimal shell
gsettings set org.toren.shell desktop-shell desktop   # ASURA's full desktop
```

Then log out and back in. The setting is also on the Hub's Desktop & Dock page. If the
desktop exits within 15 seconds three times in a row, it is restarted after a pause (never
replaced by Toren's minimal shell) and `~/.local/state/toren/quickshell.log` says why.

## Keyboard shortcuts

Unchanged. Toren's keybindings (`session/hyprland/binds.conf`) run `toren ipc call toren
<function>`; `toren/TorenBridge.qml` answers all twelve of those functions in this desktop:

| Shortcut                     | Toren call                             | In the desktop                    |
| ---------------------------- | -------------------------------------- | --------------------------------- |
| Super+Space, Super+Alt+Space | `togglePopover launcher` / `menu`      | overview with search              |
| Super+Escape, Super+N        | `togglePopover quick` / `sidebar`      | right sidebar                     |
| overview keys                | `toggleOverview`, `overviewDesktop ±1` | overview, workspace step          |
| Alt+Tab, Alt+Shift+Tab       | `advanceSwitcher` / `reverseSwitcher`  | cycle windows                     |
| Ctrl+Alt+Delete              | `session`                              | session menu                      |
| Super+Shift+T                | `ocr`                                  | region selector, text recognition |
| cheatsheet key               | `toggleCheatsheet`                     | cheatsheet                        |
| clipboard key                | `toggleSurface clipboard`              | overview, clipboard search        |

The stash and visualizer surfaces are Toren's own and do nothing in this desktop.

## What Toren changes

The tree is upstream's, byte for byte, and `vendor.sh verify` (run in CI) fails on any edit. Only
these differ, and each is regenerated by `vendor.sh sync`:

- `shell.qml` is an overlay: upstream's entry point plus the `TorenBridge {}` above.
- `modules/ii/dock/Dock.qml` is an overlay: an island dock with only the apps, floating above
  the bottom edge, no pin or overview button. It auto-hides while a window is focused and comes
  back at the bottom edge (Settings > Interface > Dock > Auto-hide; off keeps it shown).
- The Settings pages (`modules/settings/{Interface,General,Services,Bar}Config.qml`) are
  overlays offering what Toren's desktop uses: the dock's Auto-hide switch, no AI, anime or
  translator options (the left sidebar is not loaded), no utility buttons, no workspace options
  the bar ignores.
- `modules/ii/bar/Workspaces.qml` is an overlay: the bar shows only the workspaces that exist
  (the active one and those with windows), each with its app's icon, instead of ten slots
  with dots for the empty ones.
- `modules/ii/bar/BarContent.qml` is an overlay: the bar's layout. Workspaces at the start, the
  clock and date alone in the centre, the resources at the end; no active-window title.
  `Resources.qml` and `Resource.qml` are the labelled CPU / RAM / SWAP readouts with a thin
  usage bar (swap only while in use).
- Upstream speaks Hyprland's Lua IPC (Hyprland 0.55+); Toren ships Hyprland 0.49. The eight
  files with Lua dispatches (marked `T` in `manifest.txt`) are rewritten to hyprlang dispatchers
  by `hyprlang.py`, for example `hl.dsp.focus({workspace = 3})` to `workspace 3`. A form the
  translator does not know stops the sync instead of being guessed.
- `modules/common/widgets/shapes` is upstream's git submodule,
  vendored at the commit the tree points to, without its Apache-2.0 `LICENSE` (kept here as
  `LICENSE.apache-2.0`).

To change the design, change it in an overlay (add the path to `OVERLAYS` in `vendor.sh`, and
the file becomes Toren's) or in the desktop's own settings, which it keeps in
`~/.config/illogical-impulse/config.json` and edits through its settings window.

## Polkit

The session has one polkit agent. In this desktop it is `modules/ii/polkit`, and
`torend` does not register its own (`system/runit/user-services/torend/run`).

## Fonts

Material Symbols Rounded, Space Grotesk and JetBrains Mono NF ship with Toren. The desktop's
defaults also name Google Sans Flex and Readex Pro, which are not in the image; text set in them
falls back to the default sans until they are installed or the fonts are changed in the desktop's
settings.
