# The end-4 desktop

`shell-end4/` is end-4's [illogical-impulse](https://github.com/end-4/dots-hyprland) desktop:
the complete `ii` Quickshell config (bar, vertical bar, dock, left and right sidebars, overview
and search, notifications, OSD, media controls, cheatsheet, lock screen, session menu, region
selector, screen corners, overlay widgets, wallpaper selector, settings), at the commit pinned in
`vendor.sh`. It is the default desktop shell: `org.asura.shell desktop-shell` is `end4`.

## Switching

```bash
gsettings set org.asura.shell desktop-shell asura   # ASURA's own shell
gsettings set org.asura.shell desktop-shell end4    # end-4's desktop
```

Then log out and back in. The setting is also on the Hub's Desktop & Dock page. If the end-4
desktop exits within 15 seconds three times in a row, the session falls back to ASURA's shell
and `~/.local/state/asura/quickshell.log` says why.

## Keyboard shortcuts

Unchanged. ASURA's keybindings (`session/hyprland/binds.conf`) run `asura ipc call asura
<function>`; `asura/AsuraBridge.qml` answers all twelve of those functions in this desktop:

| Shortcut | ASURA call | In the end-4 desktop |
|---|---|---|
| Super+Space, Super+Alt+Space | `togglePopover launcher` / `menu` | overview with search |
| Super+Escape, Super+N | `togglePopover quick` / `sidebar` | right sidebar |
| overview keys | `toggleOverview`, `overviewDesktop ±1` | overview, workspace step |
| Alt+Tab, Alt+Shift+Tab | `advanceSwitcher` / `reverseSwitcher` | cycle windows |
| Ctrl+Alt+Delete | `session` | session menu |
| Super+Shift+T | `ocr` | region selector, text recognition |
| cheatsheet key | `toggleCheatsheet` | cheatsheet |
| clipboard key | `toggleSurface clipboard` | overview, clipboard search |

The stash and visualizer surfaces are ASURA's own and do nothing in this desktop.

## What ASURA changes

The tree is upstream's, byte for byte, and `vendor.sh verify` (run in CI) fails on any edit. Only
these differ, and each is regenerated by `vendor.sh sync`:

- `shell.qml` is an overlay: upstream's entry point plus the `AsuraBridge {}` above.
- Upstream speaks Hyprland's Lua IPC (Hyprland 0.55+); ASURA ships Hyprland 0.49. The eight
  files with Lua dispatches (marked `T` in `manifest.txt`) are rewritten to hyprlang dispatchers
  by `hyprlang.py`, for example `hl.dsp.focus({workspace = 3})` to `workspace 3`. A form the
  translator does not know stops the sync instead of being guessed.
- `modules/common/widgets/shapes` is upstream's git submodule (end-4/rounded-polygon-qmljs),
  vendored at the commit end-4 points to, without its Apache-2.0 `LICENSE` (kept here as
  `LICENSE.apache-2.0`).

To change the design, change it in an overlay (add the path to `OVERLAYS` in `vendor.sh`, and
the file becomes ASURA's) or in end-4's own settings, which it keeps in
`~/.config/illogical-impulse/config.json` and edits through its settings window.

## Polkit

The session has one polkit agent. In this desktop it is end-4's (`modules/ii/polkit`), and
`asurad` does not register its own (`system/runit/user-services/asurad/run`). After a crash
fallback to ASURA's shell, the daemon's agent is off until the next login.

## Fonts

Material Symbols Rounded, Space Grotesk and JetBrains Mono NF ship with ASURA. end-4's
defaults also name Google Sans Flex and Readex Pro, which are not in the image; text set in them
falls back to the default sans until they are installed or the fonts are changed in end-4's
settings.
